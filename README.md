# Viewtube 
https://viewtube2016.lovable.app

IMPORTANT:
- Do NOT use images.
- Do NOT use image placeholders.
- Use CSS-only shapes, gradients, icons, text, and colored blocks where visual thumbnails would normally appear.
- This is a visual recreation/inspired interface, not the current YouTube design.
- Make it feel like an authentic 2016-era desktop website.

TECH:
- Use HTML, CSS, and JavaScript.
- Use a clean component-based structure if using React.
- No backend required.
- Make all interactions functional on the frontend.

PAGE STRUCTURE:

1. TOP HEADER
- White horizontal header approximately 56px tall.
- YouTube-style logo on the left using text/CSS, with a red rounded rectangle play icon.
- Large centered search bar.
- Search button on the right side of the search field.
- "Upload" text/button.
- Notification/bell icon.
- User/profile circle on the far right.
- Thin light-gray bottom border.

2. LEFT SIDEBAR
Create a narrow vertical navigation sidebar.
Items:
- Home
- My Channel
- Trending
- Subscriptions
- History
- Watch Later

Use simple CSS/icon symbols instead of image assets.
Below that, add a "SUBSCRIPTIONS" section with several channel names.
Keep the sidebar visually similar to an older YouTube desktop layout.

3. MAIN HOME CONTENT
Create a wide content area with a light gray/off-white background.

At the top create a featured/recommended video section:
- Large video card on the left.
- Use a CSS-generated thumbnail area instead of an image.
- Thumbnail should look like a colorful video preview using gradients and geometric shapes.
- Add a play-duration badge in the bottom-right.
- Video title underneath.
- Channel name and view count below the title.

To the right, display 3 smaller recommended videos stacked vertically.
Each should have:
- CSS thumbnail
- Duration badge
- Blue/gray video title
- Channel name
- View count

4. RECOMMENDED CHANNEL ROW
Create a horizontal section titled:
"Recommended channels"

Show 5–6 channel cards.
Each card should contain:
- Circular CSS avatar
- Channel name
- Subscriber count
- Red "Subscribe" button

5. VIDEO GRID
Create a section titled:
"Popular videos"

Display a 5-column desktop grid.
Each video card should contain:
- 16:9 CSS-only thumbnail
- Random geometric/colorful thumbnail design
- Duration badge
- Video title
- Channel name
- View count
- Upload time

Use realistic sample titles such as:
- "10 Things You Didn't Know About Gaming"
- "Best Moments of 2016"
- "Funny Compilation"
- "How To Make Something Amazing"
- "Top 10 Viral Videos"
- "Epic Challenge"
- "The Best Video Ever"
- "Behind the Scenes"

6. OLD YOUTUBE VISUAL STYLE
The design should strongly resemble the 2016 era:
- Mostly white UI
- Very light gray page background
- Red accent color
- Blue links
- Small Roboto/Arial-style typography
- Thin borders
- Subtle shadows
- Compact spacing
- Rectangular video cards
- Minimal rounded corners
- Avoid modern glassmorphism
- Avoid huge typography
- Avoid modern gradients in the UI itself
- Avoid dark mode
- Avoid modern YouTube Shorts-style elements

7. VIDEO WATCH PAGE
Also create a second route/page for a video watch screen.

Layout:
- Large 16:9 video player area on the left.
- The player should be a CSS mock player with a dark gray/black background.
- Center a large white play button.
- Bottom controls:
  play button, progress bar, volume, timestamp, settings, fullscreen.
- Video title below.
- Channel information underneath.
- Red Subscribe button.
- Like/dislike buttons.
- Share and Add to buttons.
- Description section.
- Right sidebar containing "Up next" videos.

8. CHANNEL PAGE
Create a channel page inspired by 2016 YouTube:
- Large blue/colored CSS channel banner.
- Channel avatar.
- Channel name.
- Subscribe button.
- Navigation tabs:
  HOME
  VIDEOS
  PLAYLISTS
  CHANNELS
  DISCUSSION
  ABOUT
- Video grid below.

9. INTERACTIONS
Implement:
- Search field filtering video cards.
- Sidebar navigation changes active item.
- Subscribe buttons toggle between "Subscribe" and "Subscribed".
- Like button toggles active state.
- Video cards are clickable.
- Clicking a video opens the watch page.
- Responsive sidebar behavior.
- Hover effects similar to older YouTube, not modern animated effects.

10. RESPONSIVE DESIGN
Desktop should be the primary target, resembling a 2016 desktop YouTube website.
Also support tablet and mobile:
- Collapse sidebar on smaller screens.
- Reduce video grid columns.
- Stack watch-page content vertically.

11. DETAILS
Use realistic fake data.
Do not use copyrighted YouTube assets or downloaded images.
Create the YouTube-style logo entirely with HTML/CSS/text.
Use CSS-generated thumbnails with different colors, patterns, circles, rectangles, and text.

FINAL RESULT:
The finished website should immediately look like someone opened YouTube on a desktop computer in approximately 2016—not modern YouTube.

Prioritize accurate 2016-era spacing, typography, navigation, video grids, search header, sidebar, recommendation rows, and red Subscribe buttons.
